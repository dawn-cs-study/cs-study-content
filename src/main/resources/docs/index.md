# Markdown 샘플 문서
## 1. 제목과 문단
Markdown은 간단한 문법으로 문서를 꾸밀 수 있습니다.  
여기에 일반 문단을 작성할 수 있습니다.

### 소제목 (H3)
작은 제목도 가능합니다.

---

## 2. 텍스트 꾸미기
- **굵게**: `**텍스트**`
- *기울임*: `*텍스트*`
- ~~취소선~~: `~~텍스트~~`
- `인라인 코드`: `` `코드` ``

---

## 3. 리스트
### 순서 없는 리스트
- 아이템 1
    - 하위 아이템 1-1
    - 하위 아이템 1-2
- 아이템 2

### 순서 있는 리스트
1. 첫 번째
2. 두 번째
    1. 두 번째-1
    2. 두 번째-2
3. 세 번째
